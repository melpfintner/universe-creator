# UniVerse Creator

Plataforma de criação de influenciadores virtuais com IA, identidade digital e produção de conteúdo para redes sociais.

O UniVerse Creator reúne ferramentas para estruturar identidades digitais, criar conteúdo visual, planejar campanhas UGC e acompanhar produtos em alta no TikTok Shop.

## Funcionalidades planejadas

- **Criar Influencer:** fluxo para definir personagem, aparência, nicho, personalidade e identidade visual.
- **Minha Identidade:** central para guardar e consultar as definições da identidade criada.
- **Conteúdo com IA:** ferramentas de apoio à criação de imagens, vídeos e materiais para redes sociais.
- **Campanhas UGC:** organização de ideias e peças para conteúdo de marca.
- **Produtos em alta:** análise de tendências e produtos, com categorias como beleza, moda, vitaminas e suplementos.

> O estado de cada funcionalidade deve ser confirmado no aplicativo; esta lista descreve o escopo do projeto, não uma garantia de que todos os recursos já estejam concluídos.

## Configuração e segurança

- Não inclua chaves de API, senhas, tokens ou outros segredos nos arquivos do repositório.
- Configure segredos como variáveis secretas no ambiente de hospedagem (por exemplo, Cloudflare Workers Secrets).
- Não comite arquivos `.env` nem credenciais locais.
- Antes de publicar mudanças, valide os fluxos principais e os endpoints usados pelo aplicativo.
